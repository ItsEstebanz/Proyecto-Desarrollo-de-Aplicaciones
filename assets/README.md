# 🎨 Assets

Recursos visuales del proyecto que no pertenecen a la documentación específica de un avance.

## 📄 Qué va aquí

- Logo del proyecto (`.png`, `.svg`)
- Fotos de marca / portada
- Banners
- Cualquier imagen reutilizable en docs/

## 📄 Qué NO va aquí

- Mockups → van en `docs/02-prototipo/`
- Capturas del informe → van en `docs/07-informe-ieee/`
- Iconos UI → se usan via CDN (Bootstrap Icons)
