# 📄 Informe Científico - Formato IEEE

Avance 3 del proyecto. Artículo académico que documenta el desarrollo del sistema.

## 📄 Archivos en esta carpeta

| Archivo | Contenido |
| --- | --- |
| `informe.pdf` | PDF final del artículo en formato IEEE |
| `informe.docx` | Versión editable en Word |
| `informe.tex` | (opcional) Versión LaTeX |
| `referencias.bib` | (opcional) Referencias en BibTeX |

## 📋 Estructura requerida del artículo

| Sección | Contenido |
| --- | --- |
| Título y autores | Nombre del proyecto + equipo |
| Abstract (ES + EN) | Máx. 250 palabras |
| Keywords | Mínimo 5 |
| I. Introducción | Contexto del problema |
| II. Marco Teórico | Tecnologías utilizadas |
| III. Metodología | Proceso de desarrollo |
| IV. Desarrollo | Descripción técnica |
| V. Resultados | Funcionalidades + capturas |
| VI. Conclusiones | Aprendizajes |
| Referencias | Mínimo 5 en formato IEEE |

## 📐 Especificaciones técnicas

- **Extensión:** mínimo 6 páginas (sin contar portada ni referencias)
- **Formato:** IEEE estándar (doble columna, Times New Roman 10pt)
- **Capturas:** integradas en el documento
- **Enlaces:** repositorio + sistema en producción
