# 📖 Manual de Usuario - HomeStore

Esta carpeta contiene la documentación dirigida a los usuarios finales del sistema HomeStore.

## 📄 Archivos

| Archivo | Contenido |
| --- | --- |
| `manual.md` | Manual general de uso del sistema HomeStore |
| `manual-cliente.md` | Guía específica para compradores o clientes |
| `manual-administrador.md` | Guía para colaboradores o administradores |

## 👥 Usuarios del sistema

### Visitante

Puede:

- Visualizar la página principal.
- Consultar información general de HomeStore.
- Registrarse.
- Iniciar sesión.

### Cliente o comprador

Puede:

- Iniciar sesión.
- Consultar los productos disponibles.
- Agregar productos al carrito.
- Modificar las cantidades del carrito.
- Seleccionar el método de pago.
- Seleccionar el método de envío.
- Elegir una sucursal.
- Confirmar la compra.
- Visualizar la confirmación y el número de factura.

### Colaborador o administrador

Puede:

- Registrar productos.
- Editar productos.
- Eliminar productos.
- Modificar precios, costos y existencias.
- Consultar el inventario.
- Identificar productos disponibles, con poco stock o agotados.

## 📋 Contenido del manual

El manual debe explicar:

- Cómo registrarse.
- Cómo iniciar y cerrar sesión.
- Cómo consultar productos.
- Cómo utilizar el carrito.
- Cómo completar el checkout.
- Cómo confirmar una compra.
- Cómo administrar productos e inventario.
- Cómo resolver problemas frecuentes.
- Cómo contactar al soporte.

## 📸 Capturas

El manual final debe incluir capturas reales del sistema funcionando, colocadas después de cada procedimiento importante.
